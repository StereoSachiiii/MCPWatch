# MCPWatch

A monitoring and management tool for MCP (Model Context Protocol) servers.

## Features
- Real-time monitoring
- SQLite database integration
- C++ backend for performance

## Setup
1. Install dependencies:
   ```bash
   npm install
   ```
2. Build the C++ component:
   ```bash
   build.bat
   ```
3. Run the application:
   ```bash
   node index.js
   ```
